# 构筑v1.0下的十轮AI学习方法

规则、卡表、概率、1060份共享池、研习、保底和扣血冻结；训练种子、各轮验证种子、终测种子互相分离。保留最终同时淘汰并列冠军边界，不为制造唯一冠军改规则。

## 一轮训练

1. 从已通过验证的上一版策略复制候选。四个进程各跑两房间，共8个完整赛事；每房间四人从8张初始卡构筑，逐轮配对、战斗、扣血、回池、幽灵，直到至多一人存活。四分支只在轮末平均参数，不把相互依赖的同房玩家当成四个独立样本。
2. 抓牌、刷新、删牌、留费以可解释特征评分；胜负、战损、死亡与连胜败节点反馈更新。信用按0.6衰减延续到后续轮次，终局再小幅反馈到最近决策。学习率较低，参数有先验回拉与上下界，避免单局大幅覆盖经验。
3. 对战中胜者与败者都测试小幅参数变化，冻结另一方；以当前洗牌与另一个洗牌的平均收益判断是否更新，且任何一个洗牌不得明显退步。实际赛事的胜负仍只取原来那一场，训练试验不扣血、不造额外奖金。幽灵一侧不接受玩家学习更新。
4. 无路线时以阶段共性策略为主；有路线后融合历史路线及对局先验，学习路线残差。另有六阶段残差和路线×对方路线残差，后者按样本支持量收缩，避免少量克制对局记忆过重。
5. 用4个新房间测试旧策略，另4个同命名种子房间测试候选；从模板、战斗、元素竞争和淘汰开始真实重跑，不伪造固定牌组或战果。
6. 构筑更新需冠军牌组在固定旧出牌器下挑战轮换标准对手，得分至少提高1个百分点，且第5轮前专精比例下降不超过5个百分点。战斗更新需相同实际牌组的双座位对照得分提高至少1个百分点，且各有样本阶段不下降超过5个百分点。两部分可分别接受或回退。小验证集仅是保守过滤，不是统计显著性证明。

连续执行十轮，不凭终测成绩继续选参数。没有通过的经验仍记录为失败，不冒充有效更新。

## 终测

先锁定模型与哈希，再各跑32个旧/新策略完整赛事；标签不同，是两个独立赛事群体，不能把差值当作严格配对的因果估计。新冠军挑战15套标准牌组、双座位，并比较相同冠军牌组使用新/旧出牌器，以及对应完整标准牌组。另在旧策略的实际各阶段卡组上做新旧出牌器对照，检查中前期能力。

另跑24个混合策略房间，每房间1/2/3名新AI轮换席位，对其余旧AI；比较新AI实际夺冠份额与其席位占比，避免把纯自弈固定的50%对战胜率当成进步。并列冠军按人数平分冠军份额。混合赛事不学习。

发布保护：若混合赛事冠军超额的房间聚类95%区间完全低于0，保留冻结前AI为默认，候选及失败证据仍保存。终测只决定是否推荐，不继续调参、拼装新版本或追加选优。

## 决策记录与能力边界

构筑日志记录可购买候选、最高若干替代项、评分特征与贡献、当前赛事血、留费、公开下一对手。训练探索噪声在购买总分与特征贡献和之间体现；最终推断无探索噪声。战斗学习日志记录胜/败、更新范围、两种洗牌的收益及接受理由；底层出牌器已有启动/运转/斩杀、资源预算、负面清除及战术预演评分，不能读未来牌堆。

这是参考牌组引导的启发式和有界在线参数学习，并非通用最优规划器。存费只用已公布的收入与稀有度规则，未来收益是估值，不是假装知道未来卡。公开克制特征与连胜败收益仍较粗，不能声称已学会最优控败或每一步都是全局最优。相似度和专精速度是诊断，真实外部对照战果才是战力证据。
