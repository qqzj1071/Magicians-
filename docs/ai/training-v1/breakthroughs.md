# 严重克制的缓解候选与未解问题

基线每组40场，最终每组200场；牌组和双方策略都改变。下表是点估计变化，不是单卡或单项策略的因果效应；退出80%不等于已稳定达到30%反制胜率。

|初步劣势方|对手|初步胜率|最终胜率|最终95%区间|
|---|---|---:|---:|---|
|穿云箭|余烬之核|12.5%|51.0%|44.1%—57.8%|
|穿云箭|血潮|17.5%|69.5%|62.8%—75.5%|
|风痕|生命之泉|7.5%|22.5%|17.3%—28.8%|
|潮汐回响|蚀骨|10.0%|23.0%|17.7%—29.3%|
|生命之泉|反震岩核|12.5%|38.0%|31.6%—44.9%|
|蚀命|壁垒之心|2.5%|24.5%|19.1%—30.9%|

机制解释与下一步候选：穿云箭可以用更顺畅的核心启动和主弹穿盾/防穿协同压缩敌方治疗窗口；水系面对土系要区分打盾吸血、穿盾和反伤触发；蚀命面对大盾需要先建立有效挂毒与额外毒伤。以上是基于规则和最终构筑的解释，没有做单卡消融，不能声称某张牌单独造成这些变化。

最终仍有36组单边超过80%，其中18组不在初步基线名单内。它们的失败训练、局部验证与最终数据全部保留，下一轮应对这些方向增加更广候选和对手策略覆盖；本轮不再根据最终结果修改模型。
