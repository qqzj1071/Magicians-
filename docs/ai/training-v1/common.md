# 共性战斗逻辑与学习范围

卡牌和执行器规则始终为v1.0。三阶段是连续状态上的决策倾向，不是固定张数的脚本：

- 启动：未同时激活专精与路线时，提高核心、检索和下抽资源的边际价值；若当前生命不足以承受下一发，仍要比较立即防御和治疗。
- 运转：双核心齐备后，提高首次元素叠层、永久成长、有效治疗/叠盾和费用衔接的价值；重复牌不再加首次层，但仍计入其他收益。
- 斩杀：快速伤害估值达到对方有效生命的比例阈值后，进入精确条件投影；在完整主弹、副弹、引爆、反伤、毒和复活事务后判定，并且逐牌重算。
- 投影不读取未来牌序，不假设敌方下一抽停止出牌；跨抽牌边界的预测明确为“没有后续新牌”的条件结论。
- 可学习的共性参数由跨元素代表对局训练，再在不同对局和不同种子验证；路线偏好在14异路线验证；严重克制组合额外训练并向路线先验收缩，避免小样本极端权重。
- 本池两步衔接、净化净收益、核心费用保留和精确投影候选数提供新的候选维度；零默认值保留封版参考出牌器行为。某个维度是否有用取决于验证结果，不因代码存在就宣称提升。

|共性参数|采用值|
|---|---:|
|启动核心优先|450|
|启动资源|55|
|首次叠层|24|
|进入斩杀投影的阈值|1.25|
|斩杀阶段伤害偏好|1|
|本池费用衔接|8|
|费用折算|0.8|

阶段判定先检查斩杀投影触发条件，因此有合法斩杀机会时可以在双核心齐备前进入收尾；提高核心优先级不等于必须先专精再传奇。未打专精仍严格禁止预存余烬、潮汐或风痕专属效果。

不可学习的固定规则包括完整事务末判死、余烬/风痕激活门槛、伤害乘区和抽牌时序。本轮不改变它们。风险触发阈值等部分决策结构仍是人工启发式，不能声称所有逻辑都由数据学出。

起手调度仍沿用执行器保留能力牌的固定规则，本轮未训练调度或完整局内构筑轮序。
