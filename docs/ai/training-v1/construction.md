# 构筑AI：抓牌、换牌和删牌

本轮学习对象是给定牌组和候选时的边际选择，不替代尚未确定的完整局内构筑规则。训练环境允许18—26张单主系+通用卡，保持1专精、1路线传奇和2张其他传奇；资源覆盖和费用曲线受约束，史诗/稀有/普通数量不再照搬旧固定配额。该约束属于可复现实验环境。

每轮提出定向换牌、探索换牌、删牌、加牌和传奇替换；训练含各元素与最差对手，验证覆盖14条异路线并混入历史对手。目标兼顾平均得分与最差四分位，而非只对一个敌人组牌；所有对手始终面对同一固定牌组。

抓牌评分结合费用、固定面板效率、本系首次层、路线支持、过牌/检索/洗牌缺口、穿透、净化、治疗、护盾、节奏与减治疗。卡牌经验按样本数收缩；线性修正采用岭回归，并留出整个元素交叉验证。若留出误差不优于零修正，则禁用该回归层，保留规则先验和收缩后的卡牌经验。

实际训练样本67条；回归层启用。这些是完整牌组增删换的验证收益，存在上下文和候选选择偏差，不能解释成卡牌固有强度。

最终独立候选池测试：每路线3次、每次逐步从当前核心开始选牌；候选池种子在模型冻结后使用。该过程是抓牌训练课程，不冒充正式游戏轮序。

|random|45|42|1512|2.61%|
|learned|45|45|1620|33.02%|

学习排序相对纯启发式的点估计差为-0.25%。本次没有验证出逐张抓牌学习层优于纯先验；完整牌组改善主要来自候选构筑的全对手仿真筛选。抓牌模型保留为实验性工具，未来需要新候选池和新种子验证，不能把优于随机选择当作学习层有效的证据。

不合法牌组未参加对战；因此“合法牌组对战得分”不能单独用于公平比较两种方法，须同时看合法率。random是随机选择，不代表有经验的人类牌手；prior使用完全相同的费用、资源和协同先验，但禁用训练得到的卡牌奖励及回归修正，用来区分学习收益与人工启发式收益。prior对照只作归因，没有用于重新选择模型。

可调用接口：tools/round_robin/draft_learning.py中的choose_offer(deck, offer, model)，输出候选排序与传奇替换建议；模型为docs/ai/construction-model.json。未来增加完整构筑流程后，必须用相同接口重新验证前期抓牌、删除、候选过滤与刷新决策。
