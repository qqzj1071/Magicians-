# 火卡牌 · v1.2

2026-10-29固定攻防按[统一功能V分档](panel-budgets.md)：强运转70%、弱运转90%、数值牌100%；元素之间不另设区间；指定3费永久叠加牌另按稀有数值档80%校验，水系只改湍流。

读取时点与死亡截断按[独立运转与同位次结算规范](snapshot-contract.md)；逐卡绑定见[185张读取表](snapshot-audit.md)。新规范由独立strict内核执行（运转锁定继承locked），旧模式运行不覆盖本规则。

固定攻击与防御每次打出时获得，持续本场战斗。表中“首次火层”每张牌本场仅获得一次；火花首次另获1层。专精牌打出后移出本场。余烬须打出聚烬成焰后才能获得和使用，上限5。

## 名称定稿说明（2026-10-30）

火系31张采用已确认的定稿名称，其中24张显示名与原始标识不同、7张保留原名。最新四处为长明焰→拾火、燎原→星火燎原、真火→火毒、熔盾烈焰→高温炼化。

本页、总表与读取说明同步使用定稿显示名；原名对照列及JSON原始记录键保留，完整映射见[火系名称对照](fire-name-map.json)。只修改命名与对应说明，不修改卡数、稀有度、费用、攻防、效果、风味文案或运行代码，也不新增或恢复卡牌。

## 逐卡选择理由

|原名|选定名称|判断依据|
|---|---|---|
|炽焰王冠|聚烬成焰|积蓄零星余烬，再转为主弹爆发，准确概括专精。|
|余烬之核|身为洪炉|身体如炉，伤害产烬、耗烬自疗，承载输出与生存路线。|
|灰烬循环|灰烬循环|洗牌产烬、耗烬换抽牌和费用，循环含义准确。|
|燃烧血统|焚天神兵|主弹变慢、单发倍率提高，如同锻成重型法器；也避免血统暗示继承设定。|
|燎原|星火燎原|星火汇聚成燎原之势，承载首次获得5层火附魔的规模感。|
|不灭烈焰|拾火|从弃牌堆拾回火系咒语，突出取回，不暗示复活或不灭。|
|余烬引擎|回炉重造|两堆牌重新洗混并立即抽牌，表现重组可用咒语；采用候选名但保持史诗稀有度。|

|灰烬重生|拨灰续火|洗混牌堆并补充余烬，表现重新整理、继续积火，减少角色复活预期。|

|回火|回灶|洗牌后才能产烬，回到炉灶续用火力，对应循环后的收益。|
|导火索|导火索|为下一张火牌减费并强化下一发，准确表达后续动作的引子。|
