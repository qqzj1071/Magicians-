# v1.2 · 独立运转与同位次结算

2026-10-28。现行185张，本轮精简后流通库存693份；其余卡牌数值和构筑经济不变。本规范由独立模拟器 tools/sim_v12/strict.py 执行，运转收据继承locked.py；旧模式不用于新训练。

## 1. 已确定的优先级

1. 玩家存活且当前牌序未被死亡截断时，已锁定的抽牌、回费、减费、弃置、回收、选择与牌序保证兑现，不因对方正式结算而少抽、少打、跳位、压缩或改选。
2. 正式同一位次双方已提交的效果同时生效；本位完整事务结束后立即处理护命、死亡及已正式激活的复活，再进入下一位。下一位的治疗/保护不能挽救本位死亡。
3. 本次将用户“死亡或触发复活，也不能再打后面的牌”解释为：触及死亡边界就截断该方当前牌序，复活也不恢复尾段。护命保住1生命时没有死亡，不截断。若复活后尾段的理解需要改变，应显式修订，不能由程序猜测。
4. 一方真正死亡且未复活则结束战斗；双方同位真正死亡按原双死处理。复活使双方均存活时，截断方留空位，对方仍按原索引执行自己的剩余序列，已激活被动可继续反应。

## 2. 三种状态

|状态|用途|
|---|---|
|轮初事实S0|前置毒伤、衰减、到期、下一阶段资源兑现完成后的真实状态，是双方规划的起点|
|个人规划账本P|双方各自演算自己的手牌、费用、资源预算及已规划的前缀；不知道对手本轮未揭示动作|
|位次事实Ck|正式第k位开始的真实状态，用于战斗数值、真实资源、伤害和反应|

“轮”在这里指每100行动值的抽牌阶段，不是赛事轮次。即时抽牌不新建阶段。规划和牌序位次不推进全局行动值，期间不插入自然毒伤、衰减或常规飞弹。

P从S0起递进，不是永远固定初始读数。先减费后打牌、先施毒后耗毒、先获盾后开岩、治疗后预计获得潮汐等可以支持自己的后续运转。P中的战斗资源和恢复量均是预算，不是真实入账。

P不造成真实伤害，不触发真实命中、敌伤破盾、反伤、自动斩杀、死亡或复活，不预支这些未知反馈。自己可确定的主动联动可供预算，例如支付生命时预计触发永恒壁垒；正式仍只认真实支付，不复制预测盾。

## 3. 锁定范围：手牌和费用承诺，不补造战斗资源

|效果类型|读取时点|正式执行|
|---|---|---|
|抽牌/检索/弃置/置顶/回收/洗牌/回插|P|锁定实例、目标、随机动作，按前缀执行一次，不重新选牌或随机抽取|
|费用、折扣及使上述运转发生的门槛/混合分支|P|锁定数量、目标及分支；实际状态变动不撤销已承诺运转|
|纯治疗、获盾、增伤、攻防成长等战斗收益|按原卡正式打出/触发时的C|按真实资源、减疗、上限等执行，不保证达到P的预计数值|
|命中、破盾、真实支付/消耗、毒层变化、死亡、复活|C真实事件|真实发生才计一次，不认P模拟事件|
|纯战斗能力与持续效果|正式到位后|P可预演，不能提前真实激活|

混合分支如果决定抽牌/费用，就整个分支锁定，不能只保留奖励却切换另一支的代价。例如余烬心脏的低血/非低血分支，疾流的耗潮换费/治疗分支，均在P确定；但其中真实治疗和资源支付仍按C原公式计算。

纯战斗参数不为了“锁运转”全部冻结。压缩爆燃的攻击/余烬增伤门槛、巨岩的盾量档数、岩核重压的当前盾取值等在正式打出时读取C；P只用预计值辅助判断自己的运转。对手的减攻、破盾等仍能削弱真实战斗收益。

由运转结果直接决定的战斗附效保留其依赖关系：追风根据已经锁定抽到的实例是否为风附魔增加间隔成长；狂战根据已经锁定的实际弃牌成功登记增伤。正式不能改抽另一张或改弃另一张来重选附效。

## 4. 治疗、潮汐、生命与其他资源

- 所有真实治疗及其潮汐记录仍按C实际恢复量计算一次。满血空回不产生真实潮汐，新减疗可以减少真实恢复和真实潮汐；P预计治疗或预计潮汐不能直接复制进C。
- 活水在P预计有效回复大于0就锁定抽1。正式回复可能因满血/减疗为0，抽1仍兑现，但不因此补造生命或潮汐。P未取得抽牌资格时，C额外多恢复也不在本轮追加牌序。
- 疾流若P达到30潮汐，锁定兑换分支和下阶段2费；正式消耗min(30,真实潮汐)。即使不足30也兑现承诺费用，但深渊只累计真实消耗量，不补造30潮汐，不虚记成长。P未达到30则只走治疗分支，C后来有潮汐也不能改成换费。
- 主弹、潮汐风暴、生命洪流等纯战斗消费按C真实潮汐执行，伤害/治疗/最大生命成长只按实耗。P预算足够不等于正式必有同量战斗资源。
- 主动生命支付在P合法演算，正式按原卡当时C生命与百分比计算，向上取整并至少保留1生命。实付0不计真实支付，不触发永恒壁垒或细流的真实收益，但燃页等已经承诺的抽牌不取消。
- 血刃、血之回响按正式实付量记录潮汐；细流按正式合法卡牌支付触发，回复实付量50%，实付0不消耗真实细流。P的预计触发可用于锁运转，但不能占用或重发C真实触发次数。血潮主弹支付不属于细流认可的卡牌支付。
- 静水只在正式实际恢复大于0时消费真实状态并产生真实潮汐。P可预计它以规划后续费用，但不能预占真实治疗事件或强行在0恢复时消费它。
- 余烬之核、磐岩壁、风切、飞弹吸血等正式治疗只按真实事件产生。真实额外资源可以用于后续纯战斗消费或进入下一S0，但不改变已经锁定的本轮运转分支、折扣或牌序。

这里允许“规划预算满足，但正式战斗资源不足时，仍兑现已锁运转承诺”；它不保证纯战斗兑换收益。这是运转优先的明确取舍，不是把预算当成真实支付。

## 5. 毒层与护盾的跨层冲突

- 毒涌：P有毒则在P扣1并锁抽2，否则锁抽1；正式最多移除Ck确认的1毒。Ck已经无毒也不减抽牌、不切换分支。
- 枯潮：3层回费、6层额外抽牌两道门槛在P锁定；正式净化不追回资源。
- 循毒：P同时检查3层和合法弃牌，锁回收实例或抽1分支；回收不算抽牌，正式不切换。
- 开岩：P至少30盾则锁定耗盾抽1分支，C最多真实消耗30盾；不足仍抽1，不再额外送30盾。P不足则锁定获30盾分支，C后来有盾不追加抽牌。
- 万毒爆/毒潮：P可演算耗毒供后续预算，但正式伤害只依据Ck确认的耗毒量、消耗前真实攻防快照。Ck无毒就不产生毒爆；前位净化可使后位毒爆变弱或空发，后续已经锁定的运转不失效。
- 同位毒层消费和净化分别依据共同Ck确认请求，最终移除=min(Ck毒层,各减少请求之和)，本位新增层另行加上；不能清掉同位新增毒。Ck有3毒，同位万毒爆耗3、净化清3：毒爆按3层确认，最终只减3，毒爆传奇只成长3，不是6。不新增随机争夺先后。
- 主动耗盾与敌方削盾继续原比例分配。山岳之躯、碎岳之心、万钧碎盾和碎盾术只按C实际分配到的盾计算生命/转伤；P预计的盾不足以替代真实盾。
- 主动消耗、削盾、临时盾到期不视为敌伤破盾；叠盾转伤只记真实衰减；破盾返盾、余震、毒爆成长等只统计C真实变化一次。

## 6. 正式同位次与死亡边界

1. 双方确定本位已到达且允许提交的卡，空位不压缩。固定面板、首次层、能力只在本卡到位时正式生效。
2. 双方所有战斗读取均使用共同打牌前Ck，包括己方/敌方攻防、元素层、能力和负面。本牌固定面板与首次层也不加进本牌效果，计算后提交，供下一位读取。正式手牌/费用操作使用已经锁定的记录。
3. 本位新增盾、减伤、护命、复活等，从下一位起保护对方效果；同位新盾不吸收对方本位伤害，同位治疗不能挽救本位已经致命的伤害。同位净化只移除Ck已有合法负面，不抹掉同位新增部分。
4. 卡内明确先后仍成立，例如碎盾术先获盾、再主动消耗，允许使用自己本牌刚获得的盾；这不使该盾提前拦截对方同位伤害。气旋护壁本位新获得的护命与时光倒流本位新记录的复活不能保护本位，已有保护正常触发；护命保1未死亡可继续后续序列。
5. 本位全部已提交效果完成后共同处理死亡：护命优先；仍到死亡边界则截断当前牌序，再尝试已经正式激活、未过期、未用过的复活。复活不撤销截断，未到位的复活/护命不能救早位。

这里的立即死亡指本位完整同步事务后的边界，不是按程序先后取消对方同位已经提交的效果，也不能等整段牌序结束才判死。普通飞弹保留原主弹/副弹/真伤/引爆的同步发射组边界；本次不新增卡序中的穿插发射。

### 土专精主动斩杀检查

已正式激活不周山后，每次对方生命变化、每次己方盾量变化均检查一次，包括回复、支付、获盾、耗盾、敌伤扣盾、削盾、到期与转化。检查真实状态，不使用P预算。自动碎盾可在本张牌的两个行为之间插入，例如获盾后先斩杀，再处理原有主动耗盾；生命支付后先检查，再处理细流回复。激活不周山时也检查现有盾。

按当前真实可消耗盾、Ck土层/反震岩核/火倍率/敌防和已有防护确定名义致命伤害。即使对方已有护命保1，仍主动耗尽盾尝试碎盾，正常触发并消耗该保护；已有复活也正常触发。护命保1不截断序列，真正死亡/复活截断。双方同时满足时共同确认、共同碎盾，允许双死；不按座位取消。自动碎盾不视为敌伤破盾，不伪造余震或返盾。

## 7. 前缀守恒与阶段结束

每次规划出牌记录稳定实例、位次、费用、选择、随机结果及运转承诺。正式逐卡提交，禁止把P最终状态整段复制到战场。

触及死亡边界后尾段取消：不扣尾段费用或生命、不加攻防/层数、不激活能力、不建立延迟奖励、不消费尾段的抽牌/弃牌。真正死亡结束战斗；复活者的已执行前缀保留，尚未正式打出的手牌在阶段结束按规则随机回插。

早位已抽到、原计划后面才打的牌仍在手牌；早位已经弃置、原计划尾段回收的牌仍在弃牌堆。不能套用P末态导致实例丢失或提前回收。

守护者壁垒/战神徽记等阶段末判断只计正式成功前缀。P排10张而复活截断只出2张时，按2张判定。已经正式激活的下阶段收益可由仍存活的复活者保留，真正死亡者不再进入下一阶段。

渗骨毒素只登记下一阶段的检查资格，下一S0读取毒层。毒针只登记下一阶段前置施毒，不在本轮提前提供毒层。主弹耗烬奖励、余震抽牌等尚未发生的真实反馈不能被P预支。
