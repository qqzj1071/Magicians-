## 五系附魔的具体战斗效果

以下“未选/已选专精”分别使用两档系数；专精选择与专精能力牌的打出仍是两个独立条件。

- **火**：每层火附魔使来源飞弹的最终扣血乘以 `1 + 火层×1%`；火专精后为 `1 + 火层×2%`。该倍率作用于主弹、副弹、毒伤、碎盾和真实伤害的来源段。
- **余烬**：激活余烬机制后，发射时主弹消耗当前全部余烬；主弹完整伤害先乘 `1 + 火层×2.5%×实际消耗余烬`，再进行护盾/生命分配。该倍率与火附魔最终倍率相乘，副弹不消耗或获得余烬增伤。
- **水**：每层水附魔把来源造成的有效伤害转化为自身回复；当前规则为 `ceil((生命伤害 + 3×盾伤)×水层×2%)`，水专精后为 `4%`。回复受自身生命上限限制。
- **土**：本行动值双方发射前，土系玩家先获得普通护盾 `ceil((当前攻击 + 当前防御)×土层×2%)`；土专精后为 `4%`。双方在同一行动值形成发射快照，因此本次新叠加的护盾可以抵挡对方本次行动值的伤害；该护盾按普通叠盾规则处理旧盾衰减。
- **风**：风附魔使攻击间隔减少 `风层×0.5`，选风专精后为 `风层×1`；护盾穿透由实际打出天岚后提供 `5%＋2%×风层`。固定间隔变化先算，再应用百分比修正，最终向下取整且最低1。
- **毒**：来源毒附魔层与目标当前毒层共同决定毒伤：`来源毒附魔层×目标毒层×来源攻击力×2%`；毒专精后为 `4%`。毒伤跳过护盾，按目标防御的50%结算，每100行动值触发；毒层另按max(1,floor(100/当前毒层))的基础间隔自然衰减，详见毒系结算约定。

普通飞弹与正毒层毒伤最终向下取整并至少为1；疲劳沿用运行基线向上取整且至少为1；碎盾可为0，无耗潮的潮汐风暴、0毒层毒伤及未实际耗毒的毒爆不产生伤害。各卡另有明确例外时从其约定。

## 统一卡文术语

- 固定攻防每次成功打出加算；首次元素层按实例每场仅一次；额外层按卡文另算。所有“永久”只持续本场战斗。专精选择与专精能力激活分开。
- “普通增伤增加X%”属于普通增伤加算区；同区百分比加算。“直接加伤”加入对应伤害原值。“完整伤害乘以X”及火层、余烬倍率按独立乘区处理，不能混写为普通增伤。
- “同类减伤增加X个百分点”与“普通飞弹伤害降低X%”均属于普通飞弹减伤加算区；固定减伤单独扣除。实际伤害的非零保底与碎盾例外见上文。
- 防御穿透与护盾穿透各自同类加算，上限100%；独立无视剩余防御另行乘算。主弹专属效果不传给副弹。
- 潮汐“记录量增加X%”属于记录增幅加算区；潮汐“直接加伤增加X%”属于潮汐兑现增幅区，两者不改变实际消耗量。
- 回复与新增护盾按各自规则向上取整；伤害统一在适用倍率后取整，不将中间值提前取整。生命支付向上取整且至少保留1生命，不属于伤害。
- 普通护盾新叠加时旧盾保留75%并向上取整，同一步获盾合并；临时盾分批到期。主动耗盾、削盾、到期移除不视为敌伤破盾。
- 即时抽牌不创建新抽牌阶段；取回不视为抽牌；首次打出记录不因洗牌、取回或随机回插重置。阶段结束未打出的手牌逐实例随机回插摸牌堆。
- 手牌移动不能选择正在结算的本牌。明确“至多”的选择可少选；其余选择在有合法目标时必须选满，不足则全部处理，无目标跳过对应部分。
- 全部5张通用传奇沿用能力牌属性，成功打出后移出本场；五系专精与路线传奇的能力牌属性沿用v1.1。各系完整边界以相应卡表的结算约定为准。
