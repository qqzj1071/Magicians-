# 卡牌修改路径摘要 → v1.0

以下只解释最终设计如何形成，不作为任何旧数值的查询入口。最终值统一见卡表。

1. 统一六区伤害、下一次数值加算、穿透与无视防御、专精激活门槛、毒爆归类及同步争盾规则，禁止预存未激活的专属机制。
2. 火系从全程高增伤转向余烬爆发：多余烬相加、火层另乘，取消燃烧血统余烬升级；限制灰烬循环支撑牌额外余烬来源，保留余烬之核逐层回血。
3. 水系规范实际治疗记录潮汐、血潮与泉系节奏；逐步降低潮汐专属爆发和回响循环，最后同步小降四张支撑牌回复与面板。
4. 土系盾转伤改为实际衰减损失累计，支持免衰减叠盾；区分主动耗盾、敌方削盾、碎盾反伤及同时争盾。
5. 风系将风痕引爆绑定天岚第三次真伤副弹，规范递增伤害；分别强化追击与穿云的防穿/穿盾定位。
6. 毒系增长改为毒层实际增减均奖励攻击；蚀命合并为一次毒伤减防，蚀骨延长衰减，毒爆不再额外重复防穿。
7. 重做五系防守/应对附魔；加入五张批准的通用应对牌，淘汰未批准草案。净化药剂不在卡池。
8. 历次攻防调整统一收敛到稀有度价值预算，禁止靠传奇超额属性补偿；机制值遵守科学计数法尾数半单位，五系普通未专精效果严格半效。
9. 封版只整理存储与文本，253张卡的费用、攻防、元素层、实际机制参数与运行结果不再调整。旧版胜率与AI结论退出默认资料入口。

精确逐轮账目、原始对局、旧卡表与工具均可从archives/pre-v1.0.zip恢复，默认不解压、不参与检索。
