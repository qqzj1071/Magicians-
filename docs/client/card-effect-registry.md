# 卡牌效果注册表

当前注册表位于 `Scripts/Core/Cards/CardEffectRegistry.cs`，是构筑候选和战斗引擎共用的效果能力边界。

卡牌展示档案位于 `Data/Presentation/Cards/`，253张牌各有一份JSON。`Data/Presentation/card-profiles-index.json` 按中文卡名索引档案路径；档案ID根据卡名稳定生成，后续新增卡不会改变现有档案ID。

每份档案包含名称、元素（包括通用）、稀有度、战斗费用、构筑基础价格、牌面攻防、首次附魔层数、原规则文本和现行显示文本。`RuleNotes` 用于说明已确认的结算边界。规则字段是冻结卡表的展示快照，不参与战斗结算；启动时逐项校验，避免显示文案与规则数据悄悄分离。

美术在档案的 `Art` 中填写 `res://` 资源路径：`IllustrationTexture` 为插画、`FrameTexture` 为卡框、`ElementIconTexture` 为元素图标；`EffectScene`、`Sound` 为后续特效和声音预留槽。前三项由可复用 `Scenes/UI/CardView.tscn` 组装；空路径显示元素纯色占位。后两项仅保留数据槽，不自动执行场景或播放音效。

更新展示规则快照时运行 `tools/generate_card_profiles.ps1`。它保留现有 `Art` 配置，重新生成规则字段和中文索引；规则变更仍须修改权威卡表或明确的已接受文案修正，不能通过美术档案改变游戏效果。

构筑候选使用统一卡牌组件，牌效直接显示，无需悬停。战斗费用与研习购买价分别标注，免费资格与专精赠牌独立显示；界面支持单/双列和纵向滚动。`CardPresentationRegression` 实例化全部253个卡面并核验显示字段。

每张卡都必须有一条注册记录：

- `Implemented`：战斗执行器已经有明确效果实现，可以进入可玩战斗；
- `Unsupported`：效果尚未实现，构筑购买返回 `UnsupportedInSlice1`，战斗创建返回 `UnsupportedCardEffect`。

全量卡池加载会验证 253 张卡和 1060 个实体副本。`FullPoolActivationGuard` 会在切换客户端到全量卡池前扫描所有卡牌；只要仍有未实现效果，就阻止切换，避免把未实现文本静默当作无效果。

当前注册表253张均有显式执行路径，客户端已启用全量卡池。`CombatCardExecution` 统一登记即时效果、牌堆事务和仅基础攻防/首次附魔三类路径；禁止用未知卡牌的空解析器兜底。此计数表示注册覆盖情况，不等于所有交互组合的数学证明。

2026-10-26 新增：

- `ActiveShieldBurstResolver` 统一解析岩核爆破、万钧碎盾：普通叠盾，激活不周山后消耗全部护盾，按壁垒公式计算伤害，由敌方护盾吸收后扣生命，存活时分别返还30护盾或消耗量30%（向上取整）。主动消费不记为自身被敌方破盾，不递归触发反伤。
- `EmberConsumption` 记录主弹与即时卡牌的实际余烬消耗；未兑换历史进入资源快照，供灰烬账本使用。灰烬账本每次打出只兑换一次，消耗3进度获得1余烬，不足3进度则下抽+2，保留未兑换进度。
- `ActiveShieldBurstRegression` 覆盖解析器边界及权威命令路径，包括双方同时发射后的余烬记录与兑换。

本批新增大地之握、握盾：不可变 `ShieldDecayState` 记录普通获盾的旧盾实际损失，每点转为4点待发主弹直接加伤。握盾增幅加算，在完整发射后清除。免衰减获盾、临时盾、敌方削盾与主动耗盾不新增此资源。土附魔在同步发射准备阶段先获盾、先记录衰减，本发即可读取；副弹不读取转伤。激活土专精后，主动碎盾、岩核重压与反应碎盾使用独立50%穿盾分配，主弹转伤不继承该穿透。

本批回归同时修复普通飞弹扣血表达式抵消自身伤害的问题；事件记录同步读取最终生命伤害。焰心屏障的临时盾改在双方共同发射准备阶段加入，不衰减旧盾，并沿用下次抽牌清理。时光倒流接通已有默认解析器，快照保留大地之握永久激活状态，回溯不保留待发转伤/握盾增幅。

壁垒之心已接入：护盾牌检索至多5选2、下抽+1费、有盾时普通飞弹减伤15%、激活土专精后逐段按实际吸收量反伤。自动碎盾斩杀沿用盾量公式，仅自动斩杀消耗护盾并归零防御。能力牌进入本场移除区。`BastionHeartRegression` 覆盖激活、减伤加算、未破盾反伤和自动斩杀。

`CardExecutionAudit` 对253张牌各执行基础与带状态场景，共506例，检查双方命令真正结算、资源边界、卡牌身份及能力牌移除；报告写入 ../runtime/card-effect-audit.json。此报告验证执行与通用不变量，复杂组合仍由独立机制测试覆盖，不等于穷举全部组合。

完整赛事回归从基础牌和全量构筑开始，执行真实战斗直到终局，验证多轮状态、独立战斗种子、淘汰观战、幽灵战斗、唯一及并列冠军；两组种子各重放两次比较终局哈希。
