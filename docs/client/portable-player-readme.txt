开始游戏
完整解压此文件夹，双击 Magicians.exe，在主菜单选择“开始单人赛事”。
支持 Windows 10/11 64 位，无需安装 Godot、Python 或 .NET，也无需联网。

分享给朋友
发送整个 ZIP 压缩包，让对方完整解压后运行。请保留所有文件和子文件夹的相对位置。
快捷方式只记录本机游戏位置，不能单独发送代替完整游戏。
需要桌面入口时，可运行 Create-Desktop-Shortcut.vbs；移动文件夹后需重新创建快捷方式。
