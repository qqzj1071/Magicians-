# Magicians v1.1 Windows 试玩版

完整解压本文件夹后，双击 Magicians.exe 开始游玩。保留同目录的 PCK、data_Magicians!_windows_x86_64 与 runtime-data 文件夹，不要只发送 EXE。Windows 10/11 x64 无需安装 Godot、Python 或 .NET，也无需联网。需要桌面快捷方式时双击 Create-Desktop-Shortcut.vbs；移动文件夹后需重建快捷方式。

本包包含冻结的 252 张 v1.1 卡牌、构筑 v1.0 规则、2026 年 10 月 28 日小步长训练后选定的构筑与战斗 AI，以及 v1.1 卡牌表 DOCX。初始战斗属性为 1000 生命、100 攻击、40 防御，基础飞弹间隔 50。详细版本与卡牌、模型哈希记录在 BUILD-INFO.json。显示设置与日志写入用户目录，不修改发布文件。

每次新赛事生成新种子。玩家淘汰后可查看复盘或观战至冠军；可选择本轮由 AI 代理。AI 使用自己的牌组、当前可见信息与公开专精和路线，不能读取对手私有牌组或摸牌顺序。

启动时会检查文件是否缺失或被修改；校验失败请重新解压整个发布包。只读属性和公开哈希校验不是完整反作弊，不能阻止有意替换程序或修改内存。包未进行商业代码签名，Windows 可能提示下载信誉信息，不要因此全局关闭安全软件。
