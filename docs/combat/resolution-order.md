# 同步结算 · 卡牌v1.0

同一步双方读取相同快照，各自保留卡内顺序，统一提交。座位、网络与动画顺序不决定先手；同一步净化只清除快照已有负面，不抹掉对方同一步新施加部分。

## 时间与事件

初始1000生命、60攻击、20防御，0盾、0附魔层。抽牌在0、100、200……，基础每次抽5张、获得3费，费用不结转；首发固定100。默认间隔100，先固定加减再乘间隔倍率，向上取整、实现下限1；间隔调整通常在本次发射后影响下一发。

同刻依次：常规毒伤 → 毒层衰减 → 抽牌与同步出牌 → 疲劳 → 同步发射组 → 其他到期。完整事务后检查复活和死亡；同刻发射的主弹、副弹、真伤、引爆、合法反应全部完成后才判死，不因一小段致死取消对方已提交攻击。

- 双方按第1张、第2张……同步提交队列，无空步骤；本次池内同一实例最多打一次。即时返费可支持后续牌，下抽资源只在下次使用。
- 检索只查看执行时合法摸牌堆候选，选中置顶，不直接入手。洗牌不即时重抽；未打出的池内牌回堆底。能力牌打出后移出本场；附魔重复打出不加首次层，攻防及其他效果仍结算。
- 选专精后普通每层效果立即采用专精系数；余烬、潮汐、壁垒、疾风真伤、瘟疫仍需打出对应专精牌。未激活不预存专属资源或下一次增益。
- 抽牌前窗口在打出者下一抽牌阶段前到期：该刻前置毒伤与衰减先处理，再到期、抽牌、出牌。风眼屏蔽负面而不阻止叠层或自然衰减，不追补屏蔽期间伤害或引爆。
- 1500行动值起，每次抽牌出牌后疲劳失去ceil(当前生命×(5%+当前行动值×0.01%))，不经盾，不作为自身造成的伤害。

## 护盾与治疗

普通叠盾先保留ceil(旧盾×0.75)，再加新盾；同一步普通获盾合并，只衰减一次。明确免衰减或临时盾不引起旧盾损失。大地之握只记录该实际衰减损失，不计主动消费、敌伤或削盾。

同时争夺同一护盾时，按各方请求量比例分配现有盾；转伤与转生命依据实际消费。主动消费或清空不算敌方破盾；反伤不递归制造反伤链，返盾在反应窗口合并。只有自动碎盾斩杀成功才附带自身防御归零，普通破盾与主动碎盾牌不默认归零。

治疗先算减治疗、向上取整，再限制到实际损失生命，仅实际恢复记录潮汐。生命支付不低于1，不是伤害，不触发吸血。静水将主弹盾伤按卡文比例并入吸血基数，生命吸血不重复。焰心屏障按本发有效攻击在发射伤害前得临时盾，完整发射组末清空全部盾，不再次触发破盾。

## 毒、风痕与复活

主弹实际伤及生命才正常挂毒，毒伤和副弹不因此挂毒。毒层实际变化后重排衰减：基础间隔ceil(floor(200/当前毒层)×(1+延毒修正))，下限1；蚀骨在原最终间隔之后×2，最后1层不自然消失，主动消耗可清空。毒爆传奇每实际增减1毒层永久+4攻击，包括净化与自然衰减，不追溯激活前变化。

天岚第三次主弹计数从打出后0开始；风痕还需路线传奇激活。命中主弹与加成副弹叠痕，第三次真伤副弹随后引爆，包含本发刚叠的痕；真伤副弹本身不叠痕。

时光倒流只记录打出时有效攻、防、血、盾；之后200行动值内死亡，每场复活一次，恢复四项并清除自身毒和其他减益，保留死前附魔层、首次记录和已激活能力。不回滚时间、牌堆或敌方状态，不重复套用记录时已有的属性修正。双方可同时复活，之后判胜负。

稳定随机流、精确有理数及事务顺序保证重放。现有无动画执行器覆盖单主系加通用双人模拟，不代表多人赛事、混系传奇或Godot已验收。
