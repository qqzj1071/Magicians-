# 永久数值规范

机制设计值按数量级取半单位：非零绝对值写成x×10^n，其中1≤x<10，x只能为1、1.5、2、2.5……9.5。正负号不影响规范，0合法。使用十进制四舍五入到最近刻度；例如6.3→6.5、0.83→0.85、375→400、7.4→7.5。以后所有机制数值调整都遵守本条，实际卡牌、参数及模拟同步修改，不能仅将显示值舍入。

百分比按卡面显示的百分数检查，例如6.5%符合规范。五系普通附魔的未选专精系数严格等于已选专精的一半，而且两者均符合本规范；因此7.4%/3.7%应共同改为7%/3.5%，不能只将已选专精改成7.5%。选择专精与打出专精能力牌分开处理，独特机制仍按原触发条件生效。

数量、费用、固定攻击和防御使用整数，不因科学计数法刻度而更改。战斗结算得出的伤害、累积值、统计胜率、AI权重和其他派生结果不要求按本条取整；机制设计的输入系数必须合规。既有不在本轮参数表内的固定规则常量不自动重写，未来修改时需要检查。

## v1.1 当前固定攻防价值（2026-10-27用户修订）

V=(攻击+1.5×防御)/(1+(费用−1)/2)。费用0/1/2/3的分母为0.5/1/1.5/2。固定攻击、防御必须为整数，按现有攻防比例分配；同品质更高费用获得更高面板预算。

|稀有度|归一化价值区间|
|---|---:|
|普通|5—6|
|稀有|7.5—9|
|史诗|9.5—11|
|传奇|11.5—13.5|
|专精|14—16|

同稀有度最大V/最小V≤1.2，不同稀有度区间分离。本轮全卡平均价值调整为原来的0.917562倍；0.9—0.95的目标以全卡新公式均值计算，不能解释为每张牌都必须削弱。按比例分配后寻找区间内最接近的整数攻防对，保留原有零属性方向。价值V是派生结果，不受机制半单位刻度限制。燃烧血统的1.8主弹倍率按用户明确指定保留。

逐卡校准记录见[费用校准报告](../../research/v1.1-cost-value-calibration-20261027/calibration.md)。

## v1.0 历史预算（冻结数据，勿用于v1.1校准）

固定攻防价值统一使用V=攻击+1.5×防御。同稀有度所有卡牌满足(V最大−V最小)/V最小≤20%，也即V最大/V最小≤1.2，不能按元素或传奇特例豁免。预算如下：

|稀有度|固定价值区间|
|---|---:|
|普通|4—4.5|
|稀有|8—9.5|
|史诗|12—14|
|传奇|18—21|
|专精|20—24|

元素强弱调整主要分摊至史诗、稀有等支撑牌，不能靠单张传奇超额面板补偿。动态成长和条件收益另列，不混入固定面板预算。修改后运行机制网格检查、全卡固定价值与同稀有度差距检查，并以新规则重跑对战；旧版本结论须重新验证。

## v1.2功能分档覆盖（2026-10-29）

仅v1.2：数值牌沿用上述品质基准区间，强运转V区间为基准70%，弱运转为90%，各元素完全一致；具体定义、整数分配与权威分类见[功能V规则](../cards-v1.2/panel-budgets.md)。区间端点是原预算与指定比例的派生结果，不再次按半单位刻度取整。品质＋功能同档的最大/最小V≤1.2，除以本档倍率还原后的同品质最大/最小也≤1.2。弱势元素仅可在本档区间内调整或改机制，不另设专属V区间。此条不改冻结v1.1。
