# 水系

- 版本：v0.5
- 定位：以治疗、潮汐与生命交换为核心的持续战元素
- 每层水附魔：造成伤害的 2% 转化为生命；专精后 5%
- 只按实际扣到生命的伤害回血
- 核心节奏：血潮换血、生命之泉高频、潮汐回响回收

## 核心机制

所有传奇都是能力卡：打出后效果本场持续，卡牌移出本场牌组，与专精强卡相同。

专精机制（潮汐等）只有在本场已打出专精强卡「潮汐之心」后才产生与结算；未打出时相关部分不生效，稀有/史诗牌不能提前获取潮汐。

传奇能力牌的专精升级只有在本场已打出「潮汐之心」后才生效；未打出时只结算能力卡基础效果。先打出传奇、后打出专精牌时，专精牌打出后升级开始生效。

### 潮汐（专精）

- 由专精强卡「潮汐之心」激活。
- 每次实际回复生命时，记录 `回复量 × 5% × 水层数` 的潮汐值。
- 发射时消耗全部潮汐，额外造成 `ceil(潮汐值)` 伤害。
- 额外伤害先由护盾吸收，不再减防御；只有实际扣到生命的数值触发回血。
- 额外伤害造成的回血继续记录下一次潮汐；是否收敛取决于层数、路线、治疗溢出与护盾吸收。

### 血潮（以伤换伤）

- 由传奇「血潮」激活。
- 每次主飞弹发射前支付 4% 当前生命，这次发射的飞弹伤害提高支付量的 80%。
- 增伤并入飞弹伤害，正常经过护盾，不再额外减防御；造成的实际生命伤害触发水系回血。
- 升级后（需已打出「潮汐之心」）：水附魔的治疗转化比例由每层 5% 提高至 7%。
- 血潮路线的支援牌可以把支付/损失的生命按比例记录为潮汐（需已打出「潮汐之心」）。
- 支付生命不是伤害，不触发回血与潮汐记录。

### 泉流（生命之泉）

- 由传奇「生命之泉」激活。
- 攻击间隔减少 `10 + 水层数`；飞弹无视 20% 防御（目标防御按 80% 计算）。
- 路线史诗「奔流」提供永久的攻击间隔 ×0.9。
- 专精升级：无。

### 回响（潮汐回响）

- 由传奇「潮汐回响」激活。
- 主飞弹发射消耗全部潮汐并额外造成伤害；结算后返还消耗量的 20%，不设返还上限或潮汐上限。
- 升级后（需已打出「潮汐之心」）：潮汐记录比例由 5% 提高至 7%。

## 设计注意

- 水系没有专属基础牌：所有水系卡牌都是附魔牌，首次打出水 +1 层。
- 水系与毒不兼容：毒伤不回血。
- 水系与土都能拖，但水靠回血，土靠护盾；避免机制重叠。
- 治疗受最大生命限制；溢出治疗不转化为其他资源。
- 治疗数值按叠盾端的约 60–70% 校准；具体数值待模拟。
- 支付生命向上取整，且支付后生命不会低于 1。
- 生命之泉不提供直接回血；高频发射通过水层触发回血。
- 攻击间隔先结算固定加减值，再乘以乘法修正；乘法修正之间相乘。
- 防御穿透按目标当前防御计算，多个穿透效果加法叠加，上限 100%（目标防御最低为 0）。
- “飞弹伤害 +X%”只作用于飞弹基础伤害；真实伤害与潮汐额外伤害不受影响。
- 专精升级依赖专精牌已打出；快速过出「潮汐之心」的构筑价值提高。
- 路线传奇最多持有 1 张，因此血潮与潮汐回响不能同时持有；分别测试各路线的治疗与潮汐成长。
- 暂不对水附魔总治疗转化比例、潮汐记录比例增加额外上限；潮汐回响仍不设返还与储量上限。高层表现与续航强度留待战斗模拟后调整。
- 5 层「深渊潮」是纯层数加速，不定义路线。
- 数值是 1000 血尺度草案，待模拟。
