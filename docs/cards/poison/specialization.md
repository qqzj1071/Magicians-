# 毒系 · 专精强卡

## 万毒之源

- 费用：3
- 属性：+14 攻击 / +6 防御
- 打出时：毒系 +2 层（毒附魔层数）
- 独特机制“瘟疫”：
  - 毒层 >0 时，目标攻击降低 `floor(2 + 0.5 × 毒附魔层数 × 毒层数)`，防御降低 `floor(2 + 0.3 × 毒附魔层数 × 毒层数)`。
  - 减益动态更新：毒层变化后立刻按新数值重算；毒层为 0 时没有减益。
  - 减益在毒伤结算前更新，因此本次毒伤使用更新后的敌方防御。
  - 毒伤不穿盾，但受 50% 防御减免，保底 1。
  - 0 毒层不触发常规或额外毒伤，不应用保底 1 点伤害；以任何方式增加毒层后，按增加后的总层数重置衰减计时。
  - 只有主飞弹实际打到生命才叠毒层；副弹不能叠层；伤害全被盾吸收则不会上毒。
- 示例：
  - 5 毒附魔层 + 5 毒层：目标攻击 -14 / 防御 -9。
  - 5 毒附魔层 + 10 毒层：目标攻击 -27 / 防御 -17。
- 打出后移出本场牌组。

## 设计注意

- 毒系对护盾很弱；先用飞弹/风系/火系破盾才能稳定叠毒层。
- 减益随毒层动态变化，高毒层时非常强；衰减机制是主要限制。
- 毒伤是“毒附魔层数 × 毒层数”的双乘，需要重点监控后期强度。
- 毒系怕爆发；上毒前可能已经被打死。
