# 毒系

- 版本：v0.5
- 定位：持续伤害与减益
- 核心节奏：先叠毒，再用动态减益与毒伤持续压制

- `rare.md`：稀有毒系附魔与路线支撑
- `epic.md`：史诗毒系附魔与路线支撑

## 核心机制

### 毒附魔层数与毒层

- **毒附魔层数**：由毒系卡牌提供，类似其他元素的附魔层数。
- **毒层**：由主飞弹实际打到生命后叠加；副弹不能叠层。
- 两者是独立资源，毒伤与专精减益都会同时使用这两个数值。

### 毒伤

- 毒层 >0 时，每次抽牌阶段**前**结算一次；0 毒层不触发常规或额外毒伤，不应用保底 1 点伤害。
- 毒伤 = `max(1, ceil(攻击力 × 1%/2.5% × 毒附魔层数 × 当前毒层 - 50% × 敌方当前防御))`。
  - 普通每层比例 1%，专精后 2.5%。
  - 毒伤先由护盾吸收，不穿盾。
  - 毒伤不回血。
- 若同一行动值同时触发毒伤与毒层衰减，先结算毒伤，再衰减。

### 叠层与衰减

- 每次主飞弹实际打到生命 +1 毒层；副弹不能叠层。
- 每 `floor(200 / 当前毒层数)` 行动值衰减 1 层。
- 每次层数减少后，按新层数重新计算下一次衰减。
- 以任何方式增加毒层后，均按增加后的总层数重置衰减计时，包括主飞弹、速腐、枯潮、固毒等效果。
- 毒层为 0 时停止衰减。

### 专精减益

- 由专精强卡「万毒之源」激活。
- 毒层 >0 时：
  - 目标攻击降低 `floor(2 + 0.5 × 毒附魔层数 × 毒层数)`。
  - 目标防御降低 `floor(2 + 0.3 × 毒附魔层数 × 毒层数)`。
- 减益动态更新；毒层为 0 时没有减益。
- 减益在毒伤结算前更新，因此毒伤使用更新后的敌方防御。

## 设计注意

- 路线传奇全牌组最多持有 1 张；蚀命、蚀骨、毒爆不能同时持有。
- 蚀命：每次常规或额外毒伤结算时，把 `目标最大生命值 × 2% × 当前毒层` 作为基本毒伤的附加段，与该次基本毒伤合并求和；合并后只扣一次 50% 防御，再统一过盾，不穿盾、不回血。该附加不递归触发毒伤或蚀命。
- 毒爆与常规/额外毒伤结算分开，不触发蚀命；0 毒层不产生毒伤、毒爆伤害或蚀命伤害。

- 毒系对护盾很弱：打盾不叠层，需要先破盾。
- 毒伤是“毒附魔层数 × 毒层数”的双乘，后期成长很快；衰减机制是主要限制。
- 高毒层时减益非常强，需要监控胜率。
- 毒系怕爆发：上毒前可能已经被打死。
- 毒与水不兼容：毒伤不回血。
- 毒系卡牌不使用立即直伤；直伤类效果改为下一发飞弹额外伤害。
- 5 层「瘟潮」是纯毒附魔层数加速，不定义路线。
