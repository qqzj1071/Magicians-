# 通用卡牌

- 版本：v0.5
- 定位：不属于五系附魔的基础牌、间隔牌、通用传奇
- 上游：`cards/README.md`

## 文件索引

- `common.md`：基础牌模板
- `rare.md`：过牌/检索/洗牌/攻防/叠盾/回复/减益/增益
- `epic.md`：高强度通用效果
- `legendary.md`：通用传奇

## 当前规模

- 普通：20 张。
- 稀有：18 张。
- 史诗：12 张。
- 传奇：8 张。

## 设计目标

- 通用卡服务所有元素，但不能强到让元素身份失去意义。
- 通用传奇保证任何专精在 3 选 1 时都有可用选项。
- 基础牌负责费用曲线、过牌、检索、节奏，不直接定义元素路线。
