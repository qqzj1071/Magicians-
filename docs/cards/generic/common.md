# 通用 · 普通

> 通用牌不属于任何元素，不提供附魔层数。  
> 初始 8 张中的攻击强化、防御强化、护盾、检索附魔、重洗也属于本文件。  
> 即时抽牌统一改为“下次抽牌阶段多抽 X 张”。

- 基础牌可同名重复；每次打出收益相同。
