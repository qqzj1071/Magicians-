# 通用 · 史诗

> 通用牌不属于任何元素，不提供附魔层数。  
> 所有通用牌都有费用与攻防数值；攻防数值持续整场。  
> 即时抽牌统一改为“下次抽牌阶段多抽 X 张”。  
> “下一发”指打出后即将发射的下一发飞弹。  
> 易伤：受到的下一次普通飞弹伤害 +X%；多个易伤加法叠加，结算一次后全部移除；毒伤、碎盾伤害、真实伤害不受影响。
