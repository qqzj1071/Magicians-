# 风系

- 版本：v0.5
- 定位：穿透护盾、高频攻击
- 每层风附魔：造成伤害的 2% 穿透护盾；专精后 5%
- 攻击间隔没有设计下限；实现上至少 1 行动值
- 核心节奏：短间隔、多次触发、叠痕引爆、穿透削防

## 文件索引

- `common.md`：普通风系附魔
- `rare.md`：稀有风系附魔与路线支撑
- `epic.md`：史诗风系附魔与路线支撑

- `specialization.md`：专精强卡「天岚」

## 核心机制

### 风痕

- 由传奇「风痕」激活。
- 每次主飞弹命中叠 1 层风痕；卡牌产生的加成副弹命中也可叠 1 层。
- 每第三次主飞弹发射真伤副弹后，真伤副弹引爆全部风痕：第 1 层 8%、第 2 层 9%、第 3 层 10%……每层比前一层高 1 个百分点，不设上限；汇总为一次真实伤害，然后清空。
- 真伤副弹本身不叠风痕；加成副弹不计入“每第三次”计数。
- 专精升级（需天岚）提高真伤副弹本身的伤害比例，不改变风痕引爆比例。

### 加成副弹

- 风系卡牌不再使用“立即造成伤害”；改为给下一发飞弹追加加成副弹。
- 加成副弹伤害 = `max(1, 固定值 + 攻击力 × 比例 - 敌方防御)`，受全额防御减免。
- 加成副弹正常参与护盾、风层穿透与对盾增伤结算。
- 加成副弹不计入“每第三次”计数；若已打出「风痕」，命中可叠风痕。
- 路线区分：风痕路线偏多段小额副弹；疾风之刃路线偏高攻击比例；穿云箭路线偏高固定值。

### 追击

- 由传奇「疾风之刃」激活。
- 追击伤害 = `上一发主飞弹本体实际总伤害（不含加成副弹与真伤副弹）× max(0, 1 - 两次主飞弹的间隔行动值 / 100) × 0.5`。
- 间隔越短追击越高；间隔 ≥100 时为 0，最高为上一发伤害的 50%。
- 追击伤害并入该发主飞弹。

### 穿透与减防

- 风层提供护盾穿透；「穿云箭」会进一步提高护盾穿透并对护盾增伤。
- 对护盾增伤只作用于由敌方护盾吸收的伤害部分；多个加成先加法叠加，再对该部分最终乘算。
- 对护盾增伤公式：`护盾吸收伤害 × (1 + 对护盾增伤加成总和)`。
- 百分比防御穿透之间乘算；永久减防是固定值，先结算，防御最低为 0。
- 「穿云箭」的专精升级提供百分比防御穿透，与其他防御穿透乘算。

### 双方叠盾

- 穿云箭路线的部分卡牌会给双方同时提供护盾，作为保命与穿透/穿盾的取舍；给敌方的护盾会被敌方正常使用。

## 设计注意

- 风系同时有穿透与高频，容易成为“通用答案”；需要低单发伤害与卡池限制。
- 极短间隔会让事件队列非常密集；实现需要性能保护。
- 加成副弹受全额防御减免，高防御对局下需要依赖主飞弹、真伤副弹或穿云箭路线的减防。
- 风系对土系护盾有明显优势；对高防御目标仍依赖攻击力。
- 5 层「飓风」是纯层数加速，不定义路线。
