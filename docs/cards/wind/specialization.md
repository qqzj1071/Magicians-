# 风系 · 专精强卡

## 天岚

- 费用：3
- 属性：+16 攻击 / +4 防御
- 打出时：风系 +2 层
- 独特机制“疾风”：
  - 攻击间隔减少 `10 + 2 × 风系层数` 行动值。
  - 每第三次飞弹攻击额外发射一段“攻击力 20%”的副弹；该副弹无视护盾与防御。
  - 副弹不触发其他系命中效果。
  - 第三次计数每场从 0 开始。
- 示例：5 层风，间隔 -20；每 3 发一次，副弹约 15 真实伤害（76 攻 × 20%）。
- 打出后移出本场牌组。

## 设计注意

- 攻击间隔没有设计下限；极短间隔会提高事件频率。
- 第三次真伤对护盾/防御都有效，是风系独特的终结手段。
- 需要性能保护，避免间隔过低导致事件队列过密。
