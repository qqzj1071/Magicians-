# 火系

- 版本：v0.5
- 定位：强攻、单次爆发
- 每层火附魔：最终伤害 +2%；专精后 +5%
- 核心节奏：低频、长间隔、单发高伤害

## 文件索引

- `common.md`：普通火系附魔
- `rare.md`：稀有火系附魔与路线支撑
- `epic.md`：史诗火系附魔与路线支撑
- `legendary.md`：传奇火系卡牌（含 5 层与路线传奇）
- `specialization.md`：专精强卡「炽焰王冠」

## 设计注意

- 火系没有专属基础牌：所有火系卡牌都是附魔牌，首次打出火 +1 层。
- 攻防数值效果持续整场，可重复叠加；间隔/机制效果只做下一发、立即或限次。
- 稀有/史诗都有攻防补正：强机制牌补正低，弱机制牌补正高。
- 不使用“直接造成伤害”的火系牌；伤害由飞弹与攻防结算。
- 即时抽牌统一改为“下次抽牌阶段多抽 X 张”。
- 卡牌中的“下一发”统一指打出后即将发射的下一发飞弹。
- 火层数同时参与基础火增伤与专精余烬倍率，注意后期乘算。
- 火系缺少防御，容易被毒/短间隔压制。
- 5 层「燎原」是纯层数加速，不定义路线；路线由另外三张传奇承担。
- 火系传奇都是能力卡：打出后效果持续，卡牌移出本场牌组，与专精强卡相同。
- 传奇 3 选 1 时，建议至少包含燎原 + 一张路线传奇 + 一张通用传奇。
