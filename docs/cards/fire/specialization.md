# 火系 · 专精强卡

## 炽焰王冠

- 费用：3
- 属性：+20 攻击 / +0 防御
- 打出时：火系 +2 层
- 独特机制“余烬”：
  - 打出后，从下一个抽牌阶段开始，每个抽牌阶段获得 1 层余烬，上限 5。
  - 发射时消耗全部余烬。
  - 每层余烬使本发飞弹伤害乘以 `1 + 火层数 × 3%`。
  - 多层余烬之间乘算。
- 示例：5 层火、3 层余烬 = `1.15³ ≈ 1.52`。
- 打出后移出本场牌组。

## 设计注意

- 火层数同时参与基础火增伤与余烬倍率，属于双重加成。
- 长间隔换高倍率；间隔 100 时基本每发吃 1 层余烬。
- 需要模拟验证不同间隔下的每行动值伤害。
