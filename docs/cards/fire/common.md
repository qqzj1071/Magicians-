# 火系 · 普通

> 火系没有专属基础牌：所有火系卡牌都是附魔牌。  
> 首次打出：火 +1 层。  
> 重复打出：不再加层，但卡牌效果仍然完整结算。  
> 攻防数值持续整场；间隔/机制效果只做下一发、立即或限次。  
> 即时抽牌统一改为“下次抽牌阶段多抽 X 张”。
