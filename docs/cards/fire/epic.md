# 火系 · 史诗

> 火系没有专属基础牌：所有火系卡牌都是附魔牌。  
> 首次打出：火 +1 层。  
> 重复打出：不再加层，但卡牌效果仍然完整结算。  
> 攻防数值持续整场；间隔/机制效果只做下一发、立即或限次。  
> 即时抽牌统一改为“下次抽牌阶段多抽 X 张”。

> 余烬的获取、消耗及相关机制只有在本场已打出「炽焰王冠」后生效；未打出时仍结算其他效果。

说明：

- 史诗牌都有攻防补正；强机制牌补正较低，弱机制牌补正较高。
- 余烬获取：史诗可以在较宽松条件下获得 1 余烬；2 余烬需要更难的条件。
- 史诗以 2 费为主，少量 1/3 费。
- “下抽”统一指“下次抽牌阶段多抽 X 张”。
- 数值是 1000 血尺度草案，待模拟。
