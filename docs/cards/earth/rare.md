# 土系 · 稀有

> 土系卡牌都是附魔牌：首次打出：土 +1 层（所有土牌统一，下表不再逐条标注）。  
> 重复打出：不再加层，但卡牌效果仍然完整结算。  
> 攻防数值持续整场；机制效果以立即、下一发或限次为主。  
> 破盾反伤、自动斩杀与壁垒公式只有在本场已打出专精强卡「不周山」后才生效；未打出时相关部分不触发。  
> 获得临时护盾不会使旧盾衰减；在你的下次完整发射组（含副弹与反应）结束后，清空全部护盾（普通与临时）。

说明：

- 稀有牌以 1 费为主，少量 2 费。
- 强机制牌攻防补正较低，弱机制牌攻防补正较高。
- **易伤**：受到的下一次普通飞弹伤害 +X%；多个易伤加法叠加，结算一次后全部移除；毒伤、碎盾伤害、真实伤害不受影响。
- “碎盾伤害”包含壁垒反应反伤、自动斩杀、主动碎盾牌与岩核重压。
- “破盾反伤/自动斩杀”需要已打出「不周山」；未打出时只结算护盾、攻防等基础效果。
- 临时护盾的说明见 `README.md` 与 `combat/rules.md`。
- 数值是 1000 血尺度草案，待模拟。
