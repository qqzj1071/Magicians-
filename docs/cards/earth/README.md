# 土系

- 版本：v0.5
- 定位：攻击的同时获取护盾，靠护盾拖住并反伤
- 每层土附魔：每次发射获得攻击力 2% 的护盾；专精后 5%
- 护盾不设上限；`新盾 = 旧盾 × 0.75 + 叠盾量`
- 旧盾只在再次叠盾时衰减，不随时间自动衰减
- 核心节奏：叠盾、抗爆发、破盾反伤、叠盾斩杀

## 临时护盾、易伤与护盾牌

- 获得临时护盾不会使旧盾衰减；临时护盾计入当前护盾。
- 在你的下次完整发射组（含副弹和反应）结束后，清空全部护盾（普通与临时）；清空不触发破盾反应。
- 易伤：受到的下一次普通飞弹伤害 +X%；多个易伤加法叠加，结算一次后全部移除；毒伤、碎盾伤害、真实伤害不受影响。
- “护盾牌”指具有获得护盾效果的牌。

## 碎盾伤害

- 包含壁垒反应反伤、自动斩杀、主动碎盾牌与岩核重压。
- 默认受 50% 敌方当前防御减免，再由敌方护盾吸收，溢出扣生命。
- 反震岩核的专精升级会将其防御减免改为 20%。
- 大地之握的专精升级会让其 50% 直接作用于敌方生命，50% 由敌方护盾吸收。
- 以上两个升级都是传奇专精升级，需已打出「不周山」。

## 设计注意

- 护盾没有上限，但有 0.75 衰减；一张大盾牌如果不再叠盾，会长期保留。
- 疲劳无视护盾，土系不能只靠盾拖到天荒地老。
- 基础破盾反伤只针对单次大额伤害；小刀磨盾不会触发。壁垒之心的专精升级会把触发改为“打盾即反”。
- 专精「不周山」同时具备破盾反伤与自动碎盾斩杀；反伤先按 50% 敌方防御减免，再由敌方护盾吸收。
- 上述护盾量、土层数与敌方属性变化标记自动斩杀待检查；事务反应窗口末尾同步检查双方，自动碎盾后自身防御归零。具体窗口、反伤禁止递归及归零范围见 [同步结算规则书](../../combat/resolution-order.md)。
- 土系怕风系穿透与毒伤绕盾；需要保留针对性。
