# Magicians! 游戏概念介绍

世界观版本：lore v0.2，2026-10-24。本文介绍产品愿景与背景，不是规则来源或客户端功能验收。完整创作设定见[世界观入口](lore/README.md)；玩法以[卡牌v1.0](cards/README.md)、[构筑v1.0](../releases/deckbuilding-v1.0/README.md)及[战斗结算](combat/resolution-order.md)为准。

## 一句话概念

**每年秋天，魔法师们带着新咒语来到魔法集会。整理你的咒语书，为飞弹附上元素，在四人魔法师大赛中击败老朋友。**

## 世界与玩家

魔法是一门生活手艺。火可以烧窑，水可以灌溉，土可以修桥，风可以送信，毒系知识可以用于草药、发酵与分解材料。魔法师是有工作和生活的人，集会让他们交换研究、吃家乡菜、见老朋友，也给了他们认真较量的舞台。

玩家扮演一名参加大赛的魔法师，在比赛间隙研习咒式、调整牌组和研究对手，在安全结界内对战。比赛失败不会导致故事中的死亡，淘汰者仍可以留在集会上观看。玩家是归来的熟人还是初次到访者，尚未锁定。

## 核心体验

- 四人淘汰、两两对战；构筑前公布下轮对手，有限共享牌池使选牌有竞争。
- 收集同系附魔形成专精，通过路线传奇组织不同打法；专精确认与打出专精牌激活机制是两个阶段。
- 战斗按行动值推进，抽牌与发射有各自节奏，附魔、护盾、恢复和持续影响形成攻防变化。
- 自动与手动是产品设计中的操作方向；研究运行器与AI验证不代表联机或客户端已全部实现。

现行规则为四人各100赛事生命，战斗基础生命1000；不在产品简介复制概率、经济和完整卡文。赛事直到至多一人存活，最终同时淘汰允许并列冠军，不承诺固定轮数收尾。

## 美术与表达

方向是有手作质感、轮廓清楚的奇幻插画：河边小镇、摊棚、公共工坊、咒语书、工作服、生活工具与元素法术。温暖的生活环境与认真竞技并存。名称先让人听懂，卡牌效果文本准确，风味文字补充人物性格。

大陆名、举办地、人物与奖励目前为创作草案；精确画风待样张确认。下一阶段先讨论代表性场景与卡面样张，再逐步推进253张卡牌的命名、效果文案审校和美术制作。
