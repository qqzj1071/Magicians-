# Magicians! 基础游戏策划案

版本：v0.2 · 2026-10-24

## 1. 项目概述

Magicians! 是一款四人淘汰制的多人魔法师竞技游戏，核心由有限共享牌池构筑、行动值驱动的战斗和元素专精组成。每年秋天，各地魔法师带着新咒语与家乡手艺来到魔法集会：他们交流研究、整理咒语书，也在魔法师大赛中认真击败老朋友。

玩家在每轮战斗之间研习卡牌、调整牌组、确定元素专精和路线，随后进入安全结界中的一对一战斗。胜负会影响整局赛事生命；战斗失败不会导致角色死亡，淘汰者仍可作为观众留在集会上。

当前卡牌与牌组构筑均为 v1.0 冻结版本。本文解释玩法与世界观，不替代唯一卡表、结算规则或数值规范。

## 2. 游戏世界观简介

魔法是一门贴近生活的手艺。火用于烧窑、烘焙和锻造，水用于灌溉、渡运、净水和疗养，土用于修桥、筑路和制陶，风用于送信、航行、磨面和乐器，毒系知识用于草药、发酵、分解材料和剂量控制。

每年秋天，魔法师们在河流与商路交汇的小镇参加魔法集会。集会包含摊位、公共工坊、藏书室、练习场和比赛广场。魔法师大赛是其中最受瞩目的活动：参赛者要在共同的设备、材料和研习额度内组织咒语，证明自己的研究和临场判断。

世界的冲突来自手艺与关系：修得牢还是修得快，祖传方法是否应该改良，研究应公开到什么程度，以及多年好友是否真的认真对待自己的进步。比赛有压力，但安全结界将法术冲击转成可记录的模拟损耗，不表现真实致命伤。

## 3. 一局游戏流程

1. 四名玩家进入赛事，每人拥有 100 点赛事生命。
2. 系统公布下一轮配对；构筑只能使用自己的牌组、已展示候选、下一对手和其他公开信息。
3. 玩家获得本轮研习点，依现行轮次规则查看两面候选牌池。
4. 玩家购买卡牌、刷新未购买位置、移除牌、确定专精，或选择与替换路线传奇。
5. 双方进行一场战斗：战斗生命基础为 1000，按行动值推进抽牌、出牌与发射。
6. 根据战斗结果扣除赛事生命，处理连胜或连败点数，淘汰赛事生命耗尽的玩家。
7. 三人阶段使用最近淘汰者的冻结记录作为幽灵对手；赛事持续到至多一名活跃玩家，最终同时淘汰允许并列冠军。

## 4. 牌组构筑流程简介

### 4.1 初始牌组

每名玩家从 8 张基础牌开始：攻击强化×2、防御强化×2、护盾、检索附魔、短促、重洗。基础牌独立发放，不占流通共享池。

### 4.2 研习与候选

构筑使用研习点。1—2 轮收入 2 点，3—5 轮收入 3 点，6 轮起收入 4 点；结余最多继承 2 点。普通、稀有、史诗、传奇的价格分别为 1、2、3、4 点。候选来自有限共享池，同名牌通常唯一，实体被购买、删除、替换或淘汰后按规则归还。

每轮通常有两面候选。玩家可以购买合法牌，也可以刷新一次；刷新消耗 1 点，只作用于未购买位置。1—3 轮首张普通牌免费，4—6 轮首张普通或稀有牌免费。删除在前 3 轮禁用，4—6 轮最多一次，7 轮起最多两次并遵循费用和保护条件。

### 4.3 构筑判断

玩家需要在元素方向、费用曲线、过牌、检索、攻击间隔、生命管理和对手信息之间取舍。有限共享池意味着拿走一张路线或高稀有度牌，也可能改变其他玩家之后能看到的选择；系统不展示他人的私有牌组或未来候选。

## 5. 战斗逻辑简介

战斗双方初始为 1000 生命、60 攻击、20 防御、0 护盾。基础飞弹伤害为攻击减防御，最低为 1；护盾优先吸收伤害，溢出才扣生命。

战斗采用双时钟。抽牌发生在 0、100、200……行动值；每次基础抽 5 张并获得 3 点费用，费用不累积。发射从 100 行动值开始，之后按当前攻击间隔进行。抽牌阶段形成一组可执行卡牌，没有持续保留的手牌；未打出的牌回到牌堆底，检索会把合法目标置顶，洗牌不会立即重抽。

同一行动值双方读取同一快照并同步提交。常规毒伤、毒层衰减、抽牌与出牌、疲劳、同步发射组和到期效果按固定顺序处理。双方同刻提交的主弹、副弹、真伤和反应都会完成后再检查死亡，座位和动画顺序不决定先手。

1500 行动值后进入疲劳阶段，抽牌与出牌会按当前生命和行动值增加损耗，避免战斗无限拖延。生命与赛事生命是两个独立状态。

## 6. 卡牌分类简介

### 基础牌

通用的攻击、防御、护盾、检索、过牌、洗牌和间隔工具，是所有牌组的基本语言。

### 附魔牌

分为火、水、土、风、毒五系。同名附魔牌通常只在本场牌组出现一次。某张附魔牌首次打出时获得一次对应元素层；之后重复打出不再增加首次层，但仍结算固定攻防和其他效果。

### 专精牌

同系附魔牌收集到 3 张后立即确定该系专精，并获得一张费用为 3 的专精牌。专精牌通常提供攻防、额外元素层和该系独特机制；必须真正打出专精牌，专属资源和机制才会激活。

### 传奇牌

传奇是高影响力的研究成果，分为五系传奇和通用传奇。它们遵循现行候选、价格、持有上限、路线限制和共享池规则；具体效果以卡文为准。

### 路线传奇

路线传奇会改变牌组运转方式。每名玩家最多同时持有 3 张传奇，其中路线传奇最多 1 张；若要更换已有路线，需要支付现行规则规定的费用，并受到同系与共享池限制。

## 7. 五系与战斗身份

| 系别 | 生活手艺 | 战斗倾向 | 专精机制 |
| 火 | 窑炉、锻造、烘焙、烟火 | 强攻、蓄热、集中爆发 | 余烬：抽牌阶段积累，发射时消耗并放大主弹 |
| 水 | 灌溉、渡运、净水、疗养 | 回复、回流、把治疗转为伤害 | 潮汐：记录实际回复，发射时转为主弹加伤 |
| 土 | 修桥、筑路、制陶、承重 | 护盾、承受冲击、破盾反应 | 壁垒：敌伤破盾时产生反应伤害 |
| 风 | 送信、风车、帆船、乐器 | 高频、间隔、穿透与副弹 | 疾风：缩短间隔，每第三次主弹追加真伤副弹 |
| 毒 | 草药、菌菇、发酵、分解 | 减益、持续伤害、侵蚀与转化 | 瘟疫：目标中毒时动态降低攻防 |

毒系不是邪恶阵营。五系是施法方法与生活文化，不是五个敌对国家，也不决定角色性格。

## 8. 专精逻辑

专精有两个必须分开的时点：

1. 确定专精：构筑中收集同系 3 张附魔后，立即确定元素方向，获得对应专精牌，已有同系附魔的专精收益提升。
2. 激活机制：战斗中实际打出专精牌，才启动余烬、潮汐、壁垒、疾风或瘟疫等独特机制。

专精后新的附魔候选集中在已选主系与通用牌；此前已经获得的异种附魔可以保留，但不能继续新增异种。专精不是把角色锁成一个职业，也不是立即预存专属资源。

## 9. 路线逻辑

路线是围绕某个机制组织整套牌组的独门理论，例如火系的余烬循环、水系的潮汐回响、土系的壁垒体系、风系的风痕体系、毒系的蚀命或蚀骨体系。路线传奇不是单纯的高数值卡，而是给玩家一个可持续追求的构筑方向。

路线选择会即时向全场播报，但只公开选择事实，不公开完整牌组。唯一的路线被他人拿走时，构筑策略需要重新评估。路线牌通常限制为每套牌最多一条，替换路线必须遵守费用、专精和共享池条件。

## 10. 传奇逻辑

传奇代表公共藏书室和历代研究中最难得的成果。它们可能提供新的牌组运转方式、资源转换、复活记录、元素强化、检索能力或特殊战斗反应。

传奇的稀缺性来自稀有度档位、有限共享实体、同名限制、每名玩家的传奇持有上限、路线最多一张，以及不同轮次的保底与类型目标。传奇不能被普通卡的规则文本概括，选择时应阅读完整效果和限制。

## 11. 游戏核心玩法与爽点分析

### 核心玩法

- 在公开对手信息下做有限资源构筑。
- 通过同系附魔把零散卡牌收束成专精。
- 选择路线，把卡牌从“好用”变成一套有明确节奏的牌组。
- 在同步行动值中安排抽牌、出牌、发射和下一次窗口。
- 观察对手公开的元素、专精、路线和赛事生命，决定进攻、保命或转向。

### 主要爽点

- 成型爽：第三张同系附魔到手，专精牌加入牌组，零散研究变成清晰流派。
- 蓄力爽：余烬、潮汐、护盾、风的节拍或毒层积累到临界点，在正确的一发兑现。
- 连锁爽：检索、洗牌、过牌和费用安排恰好接上，抽牌阶段变成连续决策。
- 读牌爽：根据公开专精、路线和赛事生命，提前准备下一轮方案。
- 逆风爽：低生命时用恢复、护盾、复活或持续减益改变战斗节奏。
- 社交爽：抢走关键路线或传奇后，比赛结束仍能一起复盘。

## 12. 专有名词解释

| 名词 | 含义 |
| 魔法集会 | 每年秋天举行的交流、交易、教学和比赛活动；民间也叫魔法大集 |
| 魔法师大赛 | 集会中的四人淘汰竞技活动 |
| 牌组 | 玩家本场携带和构筑的卡牌集合；风味文本可称咒语书 |
| 卡牌 / 咒语页 | 可被研习、加入牌组并在战斗中执行的施法内容 |
| 研习点 | 构筑阶段使用的本局资源，用于购买和刷新候选 |
| 费用 | 战斗中每次抽牌阶段获得并用于出牌的资源，不累积 |
| 赛事生命 | 跨战斗保留，决定玩家是否继续留在整局赛事中 |
| 战斗生命 | 单场对战中的生命值，基础为 1000，与赛事生命独立 |
| 行动值 | 战斗时间轴单位，用于安排抽牌、发射和到期效果 |
| 附魔层 | 首次打出附魔牌后留下的本场元素层数 |
| 专精 | 收集同系 3 张附魔后确定的主修方向 |
| 专精牌 | 确定专精后加入的强化卡；打出后激活专属机制 |
| 路线 | 围绕一个机制组织牌组的构筑理论；路线传奇最多一张 |
| 传奇 | 高影响力的稀有研究成果，包含路线传奇与通用传奇 |
| 共享池 | 所有玩家共同竞争的有限卡牌实体集合 |
| 护盾 | 优先吸收飞弹伤害的战斗状态 |
| 主弹 / 副弹 | 标准发射的主要飞弹段 / 卡牌追加的额外伤害段 |
| 毒层 | 目标身上的持续毒状态，与毒附魔层数不同 |
| 幽灵对手 / 残响 | 最近淘汰者冻结的对局记录，不会继续抓牌或学习 |
| 疲劳 | 战斗过久后按行动值增加的生命损耗 |
