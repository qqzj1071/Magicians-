# 构筑流程：新对话讨论起点

卡牌已经冻结为v1.0。以下是尚待继续设计的局内构筑框架，不属于卡牌封版，也不是已经完成的构筑AI。卡牌数值只读[当前卡表](../cards/README.md)。

## 已确认的对手信息与下一阶段目标

玩家在每轮构筑阶段以及旁观其他玩家战斗时，可以了解其他玩家已经选择的路线。因此后续构筑AI应依据已公开的路线分布、配对与观察记录来选择和调整自身路线，主动规避不利克制，并寻找反制方案。现有“每路线固定一套应对所有对手”的训练只是研究基线，不应成为正式多人构筑流程的限制。观察与调整的具体时点、候选规则及实现方式留待下一阶段细化。

本阶段卡牌平衡调整与AI基线训练已结束。后续工作集中于构筑流程的细化、实现与构筑AI模拟训练，卡牌继续使用冻结的v1.0。

- 初始基础牌方案：攻击强化×2、防御强化×2、护盾、检索附魔、间隔减半、重洗。名称匹配、基础牌是否纳入统一攻防预算、费用与局内补牌规则在构筑阶段继续确认，不能直接把历史初始牌面板套到v1.0。
- 各玩家独立卡池，首战前开始构筑。每轮多个选牌段独立出候选；普通/稀有逐步过渡到史诗/传奇，传奇使用3选1。
- 常规候选池暂按5张，附魔比例、已选元素倾向、刷新规则及是否允许混系需讨论；同名附魔不重复，基础牌是否重复保留为流程决策。
- 旧框架为同系附魔达3张触发选专精，并生成专精强卡、加入后洗牌；选专精提高普通层效果，独特能力仍须战斗中打出。专精后卡池过滤、同轮多系达标选择继续确认。
- 旧框架每轮可删牌，前5轮1次、第6轮起2次；不删专精强卡，附魔最低保留张数与删除时机需结合新流程评估。
- 传奇持有上限暂为3，路线能力上限暂为1；替换、候选不足、跨路线与叠层传奇的取舍在下一阶段确定，不使用旧固定牌组限制代替。
- 构筑结束后洗牌并进入战斗；牌组厚度、资源密度、费用曲线及启动稳定性需要用当前卡表重新验证。
