# 整体规则与项目概览

- 版本：v0.5
- 适用文档：`combat/rules.md`、`deckbuilding/rules.md`、`cards/README.md`
- 状态：规则草案；数值仍在调整

---

## 1. 世界观

每年，散落在大陆各处的魔法师都会回到同一座魔法阵前。

你们曾是同窗、朋友、对手。有人在外游历，学会了新的咒语；有人把旧咒文重新组合，创造了更强的魔法飞弹。聚会表面上是重逢，实际上是一场淘汰赛：胜利者将获得整片大陆最好的魔法阵，成为这一年最强大的魔法师。

玩家扮演其中一名魔法师，在聚会中构筑牌组、选择元素、击败朋友，最终站在魔法阵中央。

---

## 2. 核心概念

**四人淘汰 + 牌组构筑 + 行动值飞弹对战。**

- 4 名玩家两两对战，失败扣赛事血量，降到 0 淘汰，直到只剩一人。
- 战斗间从有限牌池选牌、删牌、凑同系专精、获取传奇。
- 战斗内抽牌、支付费用、发射附魔飞弹；行动值决定抽牌与发射节奏。
- 五种附魔：火、水、土、风、毒。
- 单人模式手动对战 3 个 AI；多人模式分自动池与手动池。

---

## 3. 设计支柱

1. **构筑承诺**：主修元素、专精、牌组厚度与费用曲线。
2. **节奏博弈**：抽牌时钟固定，发射间隔可变。
3. **可读的自动战斗**：多人自动模式执行玩家写的优先级，不是黑箱 AI。
4. **元素身份**：每系有明确的攻防倾向与专精机制。
5. **可复现与可训练**：确定性模拟、完整日志、无动画回放，为 AI 与平衡服务。

## 5. 游戏模式

### 5.1 单人模式

- 最终形态：4 人局 + 3 个 AI。
- 玩家手动打牌与检索；AI 自行决策。
- AI 路线：启发式决策 + 自我对弈调参。
- 实现顺序：先做 1v1 战斗实验室，再扩展到完整 4 人流程。
- 详见 `combat/ai.md`。

### 5.2 多人模式

- 4 人淘汰，赛事血量 50。
- 匹配分自动池与手动池；同一局不混用。
- 自动：玩家在战斗间设置优先级，战斗内自动执行。
- 手动：玩家在战斗内自己打牌与检索。
- 自定义房间是否允许混用待定。
- 详见 `multiplayer.md`。

---

## 6. 一局流程

1. 4 名玩家进入，赛事血量各 50，初始牌组 8 张基础牌。
2. 第 1 轮构筑在首战前进行。
3. 每轮：公布配对 → 构筑 → 两两 1v1 → 扣赛事血 → 淘汰。
4. 3 人阶段：1 场 1v1 + 1 场幽灵对局。
5. 2 人阶段：1v1，直到一人淘汰。
6. 只剩 1 人时结束。

目标：10–12 轮；第 13 轮起进入加时，扣血提高，确保收尾。

---

## 7. 战斗与构筑的分工

### 战斗内

- 行动值时间轴
- 抽 5 张、3 费、打牌
- 附魔层与飞弹
- 伤害、护盾、毒、疲劳
- 攻击间隔

详见 `combat/rules.md`。

### 战斗间

- 初始 8 张与构筑序列
- 选牌、刷新、删牌
- 专精与专精强卡
- 传奇 3 选 1
- 牌组厚度与费用曲线

详见 `deckbuilding/rules.md`。

## 8. 术语

| 术语 | 含义 |
|---|---|
| 战斗生命 | 每场战斗内的生命，默认 1000 |
| 赛事血量 | 淘汰赛血量，默认 50 |
| 行动值 | 全局时间轴；抽牌每 100，发射从 100 开始 |
| 费用 | 战斗中打出卡牌的资源；每抽 3 费，不累积 |
| 附魔层 | 元素对飞弹的永久强化层数 |
| 专精 | 同系 3 张后锁定该系，每层效果从 2% 提升到 5% |
| 专精强卡 | 专精后生成的费用 3 卡；+2 层、+20 攻防、独特机制 |
| 传奇 | 只能 3 选 1 获取的强力卡；每系至少 4 张，另有通用传奇 |
| 异种附魔 | 专精后保留的其他系附魔，每系最多 2 层 |
| 疲劳 | 1500 后按行动值比例扣当前生命 |
| 幽灵 | 3 人阶段由最近淘汰玩家牌组生成的对手 |
