# Magicians! v1.2

多人战斗与牌组构筑独立游戏。Windows v1.2 客户端已验收，现为唯一正式客户端。

解压发行 ZIP 后运行 `Magicians.exe`。内置 Python 和六风格 AI，无需安装开发环境；支持完整四人单人赛事、手动构筑与战斗、AI托管、赛事排名、当前轮复盘和分辨率设置。默认1920×1080。实时联机尚未接入。
