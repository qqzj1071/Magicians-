# 通用卡牌 · v1.2草案

读取时点与死亡截断按[独立运转与同位次结算规范](snapshot-contract.md)；逐卡绑定见[189张读取表](snapshot-audit.md)。新规范由独立strict内核执行（运转锁定继承locked），旧模式运行不覆盖本规则。

本轮按“运转优先、针对性应对为辅”重构，通用现36张，全卡现189张。基线为[v1.1卡表](../../releases/v1.1/cards.json)，历轮记录见[版本入口](README.md)。现行效果已接入独立Python模拟器tools/sim_v12；验证范围见版本入口，v1.1客户端保持原样。

通用不提供首次元素层。固定攻防每次成功打出加算，按既有品质V预算取整数；可跨元素使用的灵活性以较低机制收益、弃牌成本或延迟兑现交换，不额外提高面板。表中“手牌”指当前抽牌阶段的可执行牌组；“下阶段”仅指自身下一个抽牌阶段，不指即时抽牌。

## 统一结算边界

- 手牌弃置与手牌置顶均从自己的当前手牌选择其他实例，不能选择正在结算的本牌、弃牌堆、摸牌堆或已移出本场的能力牌。所有选择操作在有合法目标时必须执行，不能主动选0张；要求2张时必须选满2张，合法实例不足则全部处理，无目标才跳过对应操作，不妨碍无条件的其他效果。只按实际成功移动数量结算条件奖励，不预发奖励。一次效果内目标实例不能重复选择。
- 主动弃置把所选实例立即从手牌移入弃牌堆，不视为成功打出，不支付该目标费用，不获得其固定攻防、首次层或牌面效果，也不增加出牌/耗费计数。能力牌未打出即被弃置时只进入弃牌堆，不移出本场。仅保留已存在的首次打出记录，不因弃置重置。
- 主动弃置不是抽牌、洗牌或随机回插，不触发这些事件的奖励；如未来添加“弃牌时”能力，须单独定义其触发。弃牌堆中的牌可被后续合法取回或洗牌重新利用；正在结算的牌此时仍不在弃牌堆。通晓即使少抽或未抽到牌，仍从现有手牌完成一次合法弃置；狂战、坚壁、包扎须实际弃牌才兑现对应条件收益。
- 手牌置顶是立即移动原实例，不是抽牌或打出，不重置首次记录；实例绑定的本阶段减费在离开手牌时失效。置顶不保证下一阶段抽到，之后的洗牌、其他置顶及阶段结束随机回插均可改变其位置。蓄能的额外抽牌只看实际置顶成功，不绑定下阶段必须抽回该实例。
- 随机检索只在执行时合法摸牌堆内等概率抽取不重复候选，不足则全看，不窥视未来随机数；未选牌保持相对顺序。顶牌查看只看实际存在的牌，不为补足查看数量而洗牌或触发疲劳。置顶本身不触发抽牌事件。
- 即时抽牌沿用抽牌事件、疲劳及牌堆耗尽补牌规则；抽到牌加入本阶段手牌，仍需支付费用打出。即时抽牌不开始新阶段，不重复发基础费用，不兑现下阶段资源。通晓等抽牌不保证能打出新牌。
- 下阶段额外抽牌、费用、治疗与获盾均按玩家记录待兑现量；重复合法打出可以加算，仅兑现一次后清除。基础抽牌及基础费用加上所有加减项后分别最低0；未用费用在对应阶段结束归零，不无限结转。下阶段治疗及获盾在自身下一抽牌阶段开始前、该刻前置毒伤及衰减之后执行，随后发放该阶段资源；治疗受当时减治疗与生命上限限制，不按打出时快照计算。
- 净化仅移除可净化的负面，不清除永久减攻防、毒机制派生的减攻防、主动生命支付、疲劳、主动承担的间隔代价、能力激活或首次记录。毒机制派生修正始终按当前毒层及能力重新计算，净化毒层可间接改变其数值，但不能直接删除该修正。非毒负面包含风痕；可净化的临时攻防降低移除后不覆盖期间新增属性。同一步新施加的负面仍遵循同步快照边界。
- 所有普通护盾遵循旧盾衰减，同一步新增普通盾合并处理；本轮通用牌没有免衰减特例。主动削盾不视为伤害、旧盾衰减或敌伤破盾，不触发相应吸血、返盾与反伤；裂伤优先移除临时盾，移除后才计算普通主弹伤害。
- 恐惧为可净化的临时最终属性乘区，每次打出增加独立一批×0.8，重叠k批时该区为0.8^k，在其他加减及既有属性倍率之后应用；不把打出时属性锁成固定值，不逐批取整，派生伤害按既有规则取整，各批独立到期。断流封印重复打出减治疗百分点加算，服从现行减治疗上限，各批独立到期。减治疗在治疗前使用，影响实际恢复及由实际恢复产生的资源，不直接扣除已积累资源。
- 穿透与普通增伤分别按适用伤害段加算，穿透各自最高100%；主弹专属效果不传给副弹、毒伤、碎盾或真伤。
- 阶段结束仍按v1.2规则将全部未打出手牌逐实例随机回插；已经弃置或置顶的实例不再次回插。牌种、基础牌判定及同名唯一规则沿用既有定义，构筑份数与候选概率规则不变，当前库存以版本入口为准。
- 除本轮明确新增的战术零消耗分支每玩家每阶段累计回1费上限，以及风系顺风已有例外外，不新增抽牌、回费或弃牌的每阶段次数限制。低费面板可重复累积，主动弃牌也能被洗回；本方案仍需持续检查循环与组合边界，不能把静态预算核对视为终止性或平衡性证明。


- 永恒壁垒覆盖敌方伤害、毒伤、真实伤害、疲劳及实际生命支付；只按生命实际扣除量获盾，不计护盾吸收、被护命阻止的损失或未实际扣除的部分。先完成该次扣血及其合法反应，再进入获盾窗口，不抵消本次损失、不回复生命，致命损失后获盾也不能单独阻止死亡。相同同步步骤先锁定并结算伤害，不允许新盾追溯抵挡同一步已提交伤害；后续攻击段可以使用已提交的新盾。同一步获盾合并，遵循普通旧盾衰减。重复打出的每批独立到期，重叠时返盾比例加算；获盾本身不再次触发本效果。自身下一抽牌时刻仍按现行前置结算顺序处理，效果在该刻前置毒伤、毒层衰减之后、抽牌之前到期；抽牌后疲劳不再受该批保护。
- 盾之共鸣只触发一次明确的洗牌事件，正在结算的本牌、当前手牌与已移出本场的能力牌都不加入；之后获盾不依赖实际合并牌数，不即时抽牌。它负责洗牌兼防护，循环负责洗牌兼下阶段资源，重洗保留低费单纯洗牌。

## 同类参照与精简结果

- 灵感涌现2费抽2回1，仍低于狂风同费抽3回1；通晓1费抽2弃1，仍不附带追云的限定实例减费。
- 删除史诗战意沸腾；删除稀有削弱、小检索、愈合、攻守兼备、生命祝福、铁壁、锋刃；删除普通壁障、威吓、寻物、小治疗。取消重复的轻量减攻、多档小治疗及换皮延迟资源，保留即时/延迟、弃牌/回插、抽牌/回收的机制区别。
- 固定面板继续按V=(攻+1.5×防)/(1+(费−1)/2)核对；本轮独立v1.2模拟器实现，不修改冻结v1.1数据或客户端。新增回收、洗牌与返盾仍需后续组合验证。



- 战术在本牌成功打出、支付卡面费用后锁定当前全部剩余费用X，强制全部消耗。X≥1时仅记录下阶段X+1费，不触发即时回费；X=0时仅尝试立即获得1费，不记录下阶段奖励。零消耗回费上限按玩家与抽牌阶段记录，只有实际获得费用才占用；再次抽到、洗牌、弃牌取回或重复实例均不重置，即时抽牌也不重置，新抽牌阶段重置。即使已达到零消耗回费上限，X≥1的储备分支仍正常消耗与记录。
- 战术消耗的X计入本阶段实际耗费，不计生命支付，也不因回费倒扣累计值；卡面仍为0费。例：剩余0费首次触发时本阶段获得1费；剩余1/3费时本阶段清零，下阶段分别额外获得2/4费；本阶段已经领过零消耗奖励且再次在0费打出时不再回费。打出本牌是自主决定，一旦成功打出就不能拒绝消耗剩余费用。


- 2026-10-28恢复攻击强化、防御强化为初始通用普通牌，沿用v1.1的1费5攻0防、1费1攻3防，无额外效果。初始牌组各2张的例外保持不变；攻击强化、防御强化、护盾、检索附魔、短促、重洗均仅初始发放，不投入共享池，不出现在构筑候选中；其流通库存均为0。
