# 火卡牌 · v1.2

2026-10-29固定攻防按[统一功能V分档](panel-budgets.md)：强运转70%、弱运转90%、数值牌100%；元素之间不另设区间。

读取时点与死亡截断按[独立运转与同位次结算规范](snapshot-contract.md)；逐卡绑定见[189张读取表](snapshot-audit.md)。新规范由独立strict内核执行（运转锁定继承locked），旧模式运行不覆盖本规则。

固定攻击与防御每次打出时获得，持续本场战斗。表中“首次火层”每张牌本场仅获得一次；火花首次另获1层。专精牌打出后移出本场。余烬须打出炽焰王冠后才能获得和使用，上限5。
