# 七条路线机制与高胜率牌微调

用户指定的七条机制完整落实，随后依据前轮500局冻结结果，对六张胜率>55%的牌降低固定攻击1点。费用、防御、首次层、库存、AI与经济不变，V降幅4.7%—6.5%，全部在原预算内。本轮不使用中途结果继续调参。

- 旧盾实际衰减损失×200% → 旧盾实际衰减损失×100%
- 返还消耗量25% → 返还消耗量20%
- 飞弹防御穿透20% → 飞弹护盾穿透20%
- 主弹基础攻击倍率为1.8 → 主弹基础攻击倍率为2
- 目标最大生命×3%×目标毒层 → 目标最大生命×0.5%×自身毒附魔层数×目标毒层数
- (10%+(k−1)×1%) → (8%+(k−1)×2%)
- 实际支付量100% → 实际支付量150%

蚀命新增乘区使用施毒者自身毒附魔层数，目标毒层数沿用敌方当前毒层；仍只用于常规/额外毒伤，毒爆不加。风痕n层总伤害=攻击×[0.08n+0.01n(n−1)]，按单层k计算，前2层低于旧式，第3层持平，第4层起更高；按累计n层总伤害计算，前4层低于旧式，5层持平，6层起更高。生命之泉改为盾穿，不再提供防穿；与其他盾穿加算、上限100%。
