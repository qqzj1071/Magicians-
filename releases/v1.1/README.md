# Magicians! v1.1 平衡实验版

卡牌数据为[cards.json](cards.json)，现行252张；退役的守势仅保留原始记录，不进入现行卡面。v1.0数据保持冻结。

初始战斗属性1000生命、100攻击、40防御；基础飞弹间隔50，燃烧血统间隔+100%。最终间隔向下取整且至少为1。

固定攻防价值改为 **V=(攻击+1.5×防御)/(1+(费用−1)/2)**。普通5—6、稀有7.5—9、史诗9.5—11、传奇11.5—13.5、专精14—16。按原攻防比例分配整数面板，保持各品质最大V/最小V≤1.2。本轮校验252张，改动191张，全卡平均V为上版0.917562倍；高费用牌获得相应面板补偿，不能把这个倍数理解为逐卡统一削弱。

本轮路线效果：

- 燃烧血统：主弹基础倍率1.8，打出火专精后余烬系数3%，间隔+100%不变。
- 灰烬重生：2费，洗牌；仅在已打出火专精牌后，每次打出获得1余烬，不再限制每场首次；余烬容量保持原规则。
- 疾风之刃：追击衰减乘区为max(0,1−距上发行动值/50)，追击系数仍为25%。
- 穿云箭：每风层额外防穿未选/已选专精1%/2%；对盾增伤和独立无视防御均仍为15%。
- 大地之握：旧盾实际衰减损失的300%计入下一发主弹。

[全卡校准记录](../../research/v1.1-cost-value-calibration-20261027/calibration.md)包含旧值、新值与计算口径；[本轮1000场四AI完整赛事报告](../../research/ai-v1.1-cost-value-20261027-final/report.md)按最终名次+3/+1/−1/−3计分。采用修正后的淘汰顺序与并列规则，详见[测试约定](../../docs/ai/card-balance-testing.md)。
