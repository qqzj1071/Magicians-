## 开局、专精与研习

四人各100赛事血，攻击强化×2、防御强化×2、护盾、检索附魔、短促、重洗共8张，独立发放不扣流通库存。收集同系3张附魔立即确定专精、加入专精牌，已有本系附魔的专精增益也提升。专精后不购买新异种，原有异种可保留。

1—2轮收入2点，3—5轮3点，6轮起4点，结余最多继承2点。普通/稀有/史诗/传奇价格1/2/3/4，已有路线换同专精路线花2点；最多同时持有3张传奇，其中路线最多1张。传奇满额时购买新传奇需合法替换非路线传奇。每轮最多刷新一次1点，无免费刷新，只刷新未购买位置，不压缩索引或补已购位置。

1—3轮首张普通免费，4—6轮首张普通或稀有免费，共用一次资格、两面共用，未用不继承。1—3轮禁删，4—6轮最多删1张免费，7轮起最多删2张、第一次免费第二次1点；可不删，不删至8张以下，不主动删专精/路线，不删至本系少于3张。购买替换不占主动删除次数。3/6/9…连胜或连败后的下一构筑轮+1点，间断重计，双死中断。

## 共享池与重复

普通附魔/通用每种6/8份、稀有4/6、史诗3/4；同稀有度同类别每种卡名必须等份数。通用传奇每种2份，路线与叠层每种1份，共1052份；专精赠牌不入池。玩家同名唯一，仅初始攻防各2张例外；同面候选无同名。

空闲、展示、持有、下轮待归还实体分开记账，不可超发。传奇实体本轮展示过后不可再新展示；每名玩家两面也不重复展示同名传奇，下一轮清除展示记录。删除、替换、淘汰实体下轮回池；构筑结束未购候选释放；幽灵不占库存。非传奇按剩余副本倾向抽取，但联合约束使最终边际概率不等于独立抽样。

## 元素与生成

专精前每面同系附魔最多一张，附魔目标2/3/4张按20%/60%/20%，五系基础均权；刷新时第一面实际购买过的每种元素独立以10%概率获准，未获准不能为凑数量强补。专精后只生成本系与通用，65%本系软目标、35%通用（此前授权微调后接受的当前值）。部分刷新按启用位置比例随机取整，传奇计入目标；库存不足可偏离。

每轮按：归还待回池→公布配对、发研习点→预抽每人两面各8稀有度模板→联合分配首面实体→统一展示→购买与专精/路线即时全场播报→刷新串行结算→删牌、结余→战斗扣血淘汰。第二面不预占具体牌；刷新释放自己旧面未购牌，按最新库存/专精生成，同事务扣费、预留、提交，失败回滚。

具体匹配先保护传奇保底，再减少稀有度降级、类型与元素偏差；同档无合法牌向低档补，不能升级，仍无才留空。匹配采用全场约束求解而非依玩家编号先填满一人。模拟刷新轮换席位优先序；真实服务器需幂等与串行队列，客户端时间不能决定库存。联机实现不属于本次研究验收。
